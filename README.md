# QTS

Sistema de cadastro com formulário de validação em HTML, CSS e JavaScript.

## Descrição

O QTS é uma página de cadastro com campos de dados pessoais, contato, endereço e confirmação de aceitação. O objetivo do projeto é demonstrar validações de formulário no frontend, incluindo máscaras de entrada, checagem de CPF, e-mail, celular, CEP e data de nascimento.

## Funcionalidades

- Formulário de cadastro completo
- Validação de CPF
- Validação de data de nascimento
- Validação de e-mail
- Validação de celular
- Validação de CEP
- Máscaras automáticas para campos
- Mensagens de erro visuais em cada campo
- Botões para cadastrar e limpar o formulário
- Layout responsivo

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Douglas-GitProjects/QTS.git
```

2. Acesse a pasta do projeto:

```bash
cd QTS
```

3. Abra o arquivo `index.html` em um navegador.

> Como o projeto é estático, não é necessário instalar dependências ou rodar um servidor.

## Validações implementadas

- CPF com algoritmo de verificação
- Data de nascimento não pode estar no futuro
- E-mail em formato válido
- Celular com DDD e número válidos
- CEP com 8 dígitos
- Mensagens de erro exibidas diretamente ao lado do campo

## Captura de tela

O projeto apresenta um layout moderno com blocos por seção do formulário e foco em usabilidade.

Este projeto foi desenvolvido como exemplo prático de validação de formulários com JavaScript puro.
